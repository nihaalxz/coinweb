# Assets Folder — Cash Back Kart

You can upload all your project assets (images, icons, mockups, logos) here!

---

## 📁 Suggested Subfolder Structure

```
assets/
├── images/          <- Place all photography, portraits, mockups here
│   ├── hero/        <- Hero phone or card images
│   ├── about/       <- About Us section photo
│   ├── portraits/   <- Value proposition collage portraits (portrait-1, 2, 3)
│   ├── features/    <- Feature stepping stone photos
│   └── process/     <- 3-Step How It Works photos
└── icons/           <- Any custom SVG/PNG brand logos or icons
```

---

## 🔗 How to use them in `index.html`

Simply reference them using the relative path:
```html
<img src="assets/images/portraits/portrait-1.jpg" alt="Shopper Portrait" class="editorial-bw-img">
```
