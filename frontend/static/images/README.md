## 💡 Pro Tip for Styling
All images placed in this folder and displayed on the page will automatically have the crisp, editorial black-and-white look applied via CSS (`filter: grayscale(100%)`). You can upload either full-color or black-and-white images and the design will stay perfectly consistent!
